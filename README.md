# accountingPLUS — учебный кабинет

Публичная учебная версия с вымышленными данными: шесть месячных примеров Wildberries/Ozon и три годовых финансовых примера для ИП без НДС на двух режимах УСН.

Открыть: https://ikquwii.github.io/accountingplus-demo/

Выберите пример → проверьте операции и сверку → исправьте классификацию с пояснением → пересчитайте → проверьте черновик. CSV и пояснение можно скачать. Суммы в модуле расчёта считаются точно в копейках.

В разделе «Финансы» выберите один из трёх годовых примеров или заполните данные выбранного клиента. Там показаны выручка, полные управленческие расходы, прибыль, накопительные доходы/налоговые расходы, взносы ИП, налог, авансы и подтверждённые оплаты. Для УСН «Доходы минус расходы» собственные взносы учитываются в расходах, годовой минимальный налог проверяется отдельно. Перечисление ЕНП не подтверждает погашение конкретного обязательства.

Рабочая политика признания взносов изначально не подтверждена. Сначала проверьте режим/ставку, сотрудников, полноту дохода, год деятельности, остаток прошлогоднего 1%, признанные расходы и начисленные авансы. Неизвестные суммы остаются неизвестными, окончательный аванс не выдаётся при блокирующих вопросах. Сохранение всего черновика требует имени и основания; результаты вычисляются заново из текущих источников. Учебные суммы в копейках требуют округления и проверки бухгалтера перед официальным уведомлением или декларацией.

Правки сохраняются в localStorage только в вашем браузере. Это не общая база команды: разные браузеры и устройства имеют независимые данные. Имя проверяющего вводится вручную и не подтверждает личность. Кнопка сброса удаляет только данные этой учебной версии в вашем браузере.

Данные не отправляются на сервер приложения. Не используйте кабинет для настоящих клиентских документов: он предназначен для обучения, не для сдачи отчётности. Импортируется внутренний CSV, до 1 МБ и 2 000 строк; настоящие форматы WB/Ozon, XLSX, ИИ и 1С здесь не подключены. Расчёты и экспорты остаются черновиками; выплат или отправки отчётности нет.

Исходный рабочий backend находится в отдельном приватном репозитории команды. Здесь опубликован только статический учебный пакет, без ключей, учётных записей и реальных файлов.
