# accountingPLUS — учебный кабинет

Публичная учебная версия с вымышленными данными: шесть примеров Wildberries/Ozon для ИП на УСН «Доходы» без НДС.

Открыть: https://ikquwii.github.io/accountingplus-demo/

Выберите пример → проверьте операции и сверку → исправьте классификацию с пояснением → пересчитайте → проверьте черновик. CSV и пояснение можно скачать. Суммы в модуле расчёта считаются точно в копейках.

Правки сохраняются в localStorage только в вашем браузере. Это не общая база команды: разные браузеры и устройства имеют независимые данные. Имя проверяющего вводится вручную и не подтверждает личность. Кнопка сброса удаляет только данные этой учебной версии в вашем браузере.

Данные не отправляются на сервер приложения. Не используйте кабинет для настоящих клиентских документов: он предназначен для обучения, не для сдачи отчётности. Импортируется внутренний CSV, до 1 МБ и 2 000 строк; настоящие форматы WB/Ozon, XLSX, ИИ и 1С здесь не подключены. Налог показан предварительно, до уменьшений.

Исходный рабочий backend находится в отдельном приватном репозитории команды. Здесь опубликован только статический учебный пакет, без ключей, учётных записей и реальных файлов.
